# Al-shef
## Al-shef - это Telegram-бот (@Shef_analitics_bot), который помогает пользователю находить рецепты по списку имеющихся ингредиентов.
Бот использует нейросеть Gigachat для генерации списка подходящих рецептов и хранит результаты в собственной базе данных.
Пользователь может искать рецепты, сохранять понравившиеся, просматривать их позже и управлять списком сохранённых блюд.

## Используемые технологии

- Python 3.10+
- aiogram — для взаимодействия с Telegram API
- Gigachat API — для поиска и генерации рецептов
- PostgreSQL / SQLite — для хранения пользовательских данных и рецептов
- SQLAlchemy — ORM для работы с БД
- 
- Postman — тестирование API
- Chrome DevTools — анализ сетевых запросов
- Pytest / Unittest — тестирование логики бота

Перед разработкой были определены пользовательские сценарии (User Story), вариант использования (Use Case).
Подготовлены макет интерфейса.
Анализ позволил определить ключевые функции бота: поиск рецептов, сохранение и просмотр сохранённых данных.
